# 🚨 Digicel Haiti Alert System

**A public alert application for Digicel Haiti internet issues in the Southern region.**

---

## Features

- 🔴 Red alert title for Digicel Haiti
- 📍 List of affected cities in Southern Haiti (50+ cities)
- 🎙️ AI female voice explaining the issue in English, French, and Spanish
- 📱 Contact information for Gesner Deslandes
- 🚀 Deployed on Streamlit
